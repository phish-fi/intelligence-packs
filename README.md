# intelligence-packs

This repository contains intelligence packs for [phish.fi](https://phish.fi/), a phishing reporting website. Each pack provides data used to direct abuse reports to the addresses specified by its contributor.

## Contributing

To contribute an intelligence pack, [fork this repository](https://github.com/phish-fi/intelligence-packs/fork), add a pack containing your data, and open a pull request. The repository owner reviews submissions and, if accepted, merges them. Once your pack is included, abuse reports will be sent to the addresses you specified.

See the [contribution guide](https://phish.fi/docs/packs/contribute) for instructions on creating and submitting a pack.
